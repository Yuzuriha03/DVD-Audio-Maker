# 性能优化测试脚本

## 可用脚本

### 1. verify-optimizations.sh
验证所有优化配置和构建状态

```bash
./verify-optimizations.sh
```

### 2. optimization-summary.sh
显示优化状态总览

```bash
./optimization-summary.sh
```

### 3. run-performance-tests.sh
运行完整性能测试套件

```bash
./run-performance-tests.sh
```

### 4. check-rayon-config.sh
检查 Rayon 并行配置

```bash
./check-rayon-config.sh
```

### 5. verify-abc-optimization.sh
验证 A+B+C 优化模块

```bash
./verify-abc-optimization.sh
```

### 6. benchmark.cmd (Windows)
Windows 平台基准测试

```cmd
benchmark.cmd
```

## 快速开始

```bash
# 验证优化
./verify-optimizations.sh

# 查看总结
./optimization-summary.sh

# 运行测试
./run-performance-tests.sh
```

所有脚本已设置可执行权限
