# DVD-Audio Maker

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

把 FLAC、ALAC/M4A 音乐制作成 DVD-Audio ISO：支持 MLP / LPCM 编码、自动分盘、选曲菜单、专辑封面和成品验证。绿色版 Windows 应用，解压即用，无需安装。

## 下载与安装

1. 打开 [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest)，按系统下载：
   - 普通 Intel / AMD 电脑：`DVD-Audio-Maker-v1.1-win-x64.zip`
   - Windows on ARM 设备：`DVD-Audio-Maker-v1.1-win-arm64.zip`
2. 解压到自己的文件夹，双击 `DVD-Audio-Maker.exe`。
3. 保留解压目录中的 `LICENSE`、`THIRD-PARTY.md`、`THIRD-PARTY.en.md`、`NOTICE-Image.txt` 和 `NOTICE-Menu.txt`。

**系统要求：** Windows 10 / 11（x64 或 ARM64）。程序已内置所需组件，不需要另外安装运行库；EXE 所在文件夹需要可写。制作 ISO 和临时文件需要足够的磁盘空间，建议预留与成品大小相当的空间。

## 主要功能

- 将 FLAC、ALAC/M4A 无损音乐制作成 DVD-Audio ISO
- MLP 无损压缩或 LPCM 未压缩编码
- 按 DVD5、DVD9 或自定义容量自动分盘，保持专辑完整
- 选曲菜单、专辑索引、播放封面
- 制作前检查音源，制作后验证成品
- 支持中断后继续未完成的制作
- 设置保存在程序目录，便携使用，不写注册表

## 快速开始

1. **选择音源文件夹。** 每个专辑建议单独一个文件夹；程序会扫描其中的 `.flac` 和 `.m4a` 文件，包括子文件夹。请填写专辑、标题、曲序和日期标签。
2. **选择成品位置。** 指定 ISO 保存目录、光盘标题和容量。程序会按曲目顺序装盘；当前盘放不下下一张专辑时，自动开始下一张光盘。
3. **设置音频。** 通常选择“MLP 编码”。按音源和播放设备选择采样率与位深；降低参数会改变精度，提高参数不会补回音源中没有的细节。
4. **设置菜单。** 按需启用选曲菜单、专辑索引和播放封面。菜单字体已内置，无需安装。
5. **检查音源。** 点击“检查音源”，处理提示的问题。
6. **开始制作。** 检查通过后点击“开始制作”，程序会编码并生成 ISO。
7. **验证成品。** 制作完成后点击“验证成品”；通过后可用“查看成品”打开 ISO 所在文件夹。

“开始制作”会自动检查音源；检查失败会阻止制作。制作过程中可以取消，已完成的成品不会因取消而删除。

## 音源要求

- 支持 **FLAC** 和 **ALAC/M4A**（`.m4a`）。不支持使用压缩 `cmov` atom 的少见 MOV/M4A 文件；普通 M4A/ALAC 不受影响。
- 推荐使用无损音源；有损音源会保留其原有损失，不会因重新编码而恢复。
- 源采样率、位深和声道数可以与目标不同，程序会按设置转换。
- 文件名建议包含曲序；专辑、标题、艺术家、曲序和日期等标签越完整，菜单和日志越清晰。

## 音乐源文件摆放结构

推荐按“每个专辑一个文件夹”组织音乐库：

```text
音乐库/                         ← DVDA_SRC
├─ 专辑 A/
│  ├─ 01 - 曲名.flac
│  ├─ 02 - 曲名.flac
│  ├─ 03 - 曲名.m4a
│  └─ cover.jpg                ← 可选，专辑封面
├─ 专辑 B/
│  ├─ 01 - 曲名.flac
│  ├─ 02 - 曲名.flac
│  └─ cover.png
└─ 专辑 C/
   ├─ 01 - 曲名.flac
   └─ 02 - 曲名.flac
```

- `DVDA_SRC` 指向音乐库根目录；程序会递归读取其中的 `.flac` 和 `.m4a` 文件。
- **专辑按 `Album` 标签分组，不是只按文件夹名。** 请确保同一专辑所有曲目的 Album 标签一致；标签为空或互相不一致时，曲目可能被归到同一专辑或分到不同专辑。
- 曲目建议命名为 `01 - 曲名.flac`，并同时填写 `Track` 标签。程序按文件名顺序读取曲目，标签用于显示和排序。
- 一个专辑文件夹内不要再嵌套子文件夹；封面放在专辑文件夹根部。
- 同一专辑可以混用 FLAC 和 M4A，但建议整张专辑使用同一种格式。
- 输出目录（`DVDA_FINAL_DIR`）建议放在音乐库之外，避免和音源目录混在一起。

如果使用 JSON 方案，对应关系是：

```json
"DVDA_SRC": "D:/Music/MyAlbums",
"DVDA_FINAL_DIR": "D:/DVD-Audio/Output"
```

GUI 中的“音源文件夹”对应 `DVDA_SRC`，“成品位置”对应 `DVDA_FINAL_DIR`。

## 音频设置

| 编码方式 | 存储方式 | 体积与限制 | 适用情况 |
| --- | --- | --- | --- |
| MLP 编码 | 对 PCM 进行无损压缩 | 通常较小；支持 16 / 20 / 24 位 | 希望节省空间，或制作高采样率、多声道内容 |
| LPCM 编码 | 非压缩 PCM | 较大；当前支持 16 / 24 位，码率不超过 9.6 Mb/s | 希望直接存储未压缩音频 |

**相同采样率、位深、声道和 PCM 输入下，两种编码的音质相同。** LPCM 不会因为体积更大而增加音源细节。

- 目标位深：MLP 支持 16 / 20 / 24 位；LPCM 支持 16 / 24 位，20 位请使用 MLP。
- 目标 16 位且音源高于 16 位或为浮点时，默认加入 TPDF 抖动以减少量化失真；可在设置中关闭。纯 16 位及以下音源不会添加抖动。
- 源位深高于目标位深时会被转换，不是 bit-perfect；需要原样保留时，请选择与音源一致或更高的目标位深。
- 采样率：44.1、48、88.2、96 kHz 支持 1～6 声道；176.4、192 kHz 支持单声道和双声道。
- LPCM 有码率上限。例如 96 kHz / 24 位 / 6 声道约 13.8 Mb/s，不能作为 LPCM 写入；请选择 MLP 或降低目标参数。
- 极高噪声素材可能超过 MLP 码流限制；编码失败时请查看对应曲目日志，调整音频格式后重试。

## 菜单与封面

- 可为每张专辑放置封面：`cover.jpg`、`cover.jpeg`、`cover.png` 或 `cover.webp`。
- 菜单支持选曲、专辑索引和播放封面；未找到封面时使用黑色背景。
- 菜单字体已随程序提供，支持简体中文、繁體中文、日文和韩文显示。

## 任务、恢复与日志

- 默认使用系统临时目录；成功、失败或正常取消后会清理本次任务数据，只保留已输出的 ISO。
- 勾选“继续未完成的制作”后，程序会在所选工作文件夹的 `unfinished-task` 中保留未完成任务，下次启动可继续；成功并验证通过后仍会删除。
- 会话日志保存在 EXE 所在目录，文件名为 `gui-时间戳-进程号-序号.log`，只保留最近三次运行。
- 需要排查问题时，可切换到详细日志或点击“保存详细日志”。

## 常见问题

**生成 ISO 后能在普通 DVD 播放机上播放吗？**  
不能保证。DVD-Audio 需要支持 DVD-Audio 的软件或硬件播放器；普通 DVD-Video 播放器不一定支持。

**LPCM 为什么不能选 20 位？**  
当前 LPCM 路径只支持 16 / 24 位；20 位请使用 MLP。LPCM 还受 9.6 Mb/s 码率限制。

**“检查音源”失败怎么办？**  
查看提示的曲目和原因，确认文件可读、格式为 FLAC 或 M4A，并检查标签和路径。修正后可以只重新检查，不会保留跨任务缓存。

**制作或验证失败怎么办？**  
保留详细日志和对应工作目录，先检查磁盘空间、目标目录权限和音源完整性，再重试。不要仅凭生成了 ISO 就跳过验证。

**设置保存在哪里？**  
保存在 EXE 所在目录的 `settings.json`，启动时自动读取，不写入 `%LOCALAPPDATA%`。该目录必须可写；也可以用“保存方案 / 打开方案”管理 JSON 配置。

**如何卸载？**  
删除程序文件夹即可；程序不写注册表。删除前请先移走需要保留的 ISO 和日志。

## 界面语言

界面与日志支持简体中文、繁體中文、English、日本語和한국어。程序会记住上次选择的语言；也可以手动切换。
