# DVD-Audio Maker

作業の再開：作成開始時のみ「作成を続ける / 最初から作成」を確認します。失敗・キャンセル後は進捗の保存・削除を確認します。再開には元の設定を使い、ソース確認には独立した一時領域を使います。作成・検証成功後は中間ファイルを削除します。内蔵 MLP を再エンコードする独立検証は mlp-coded-v1-no-auxiliary-stamp を使用し、元のヘッダーパリティを検証した後、補助識別ストリーム全体と関連パリティビットのみを除外します。これは符号化ストリームの一致であり、ファイル全体の一致ではありません。作成直後と外部 MLP の検証はバイト単位です。

Windows 10/11 x64 に対応しています。ZIP を展開し、**DVD-Audio-Maker.exe** を起動してください。

必要なコンポーネントは内蔵され、初回起動時に自動で準備されます。初回は時間がかかる場合があります。説明書とライセンスは EXE と同じ場所にあります。

## ディスクの作成

1. FLAC/M4A の音源フォルダー、出力先、作業フォルダーを選択します。
2. ディスク名、容量、エンコード方式を設定し、必要に応じてメニューを有効にします。
3. **作成開始**を選択します。音源を確認してディスクを作成し、完成した出力を自動で検証します。変更のない音源は有効な確認結果を再利用します。
4. 生成した ISO を DVD-Audio 対応の書き込みソフトやプレーヤーで開きます。

**MLP エンコード**は PCM を可逆圧縮し、通常は同じ容量により多くの音楽を収録できます。**LPCM エンコード**は非圧縮 PCM を保存し、通常は多くの容量が必要です。どちらも非可逆圧縮ではありません。ただし、サンプリング周波数やビット深度を変更すると変換後の PCM は変わります。

**既存 MLP の読み込み**は、外部エンコーダー などの互換ツールで作成済みのファイルに使用します。対応する元音源を保管し、MLP のフォルダーを指定してください。再エンコードは行いません。変換条件が不明なリサンプリングやビット深度の変更がある場合、元音源との一致を検証できないことがあります。

設定と言語は settings.json (EXE directory) に自動保存されます。プロファイルの保存・名前を付けて保存・読み込みで JSON 設定を管理できます。旧 config.env には対応していません。中国語・英語・日本語の表示に対応しています。

アルバムを分割せず、曲順に沿って容量までディスクに収録し、入りきらない場合は次のディスクを開始します。MLP エンコードの並列数は利用可能なプロセッサーに応じて自動で割り当てられます。

中止後は作業フォルダーを保持して再実行できます。再開時は入力、設定、完成済みディスクを確認してから再利用します。操作ログは gui-*.log (EXE directory; latest 3 runs only)、作成ログは作業フォルダーの build.log に保存されます。問題が起きた場合は詳細ログを保存してください。
