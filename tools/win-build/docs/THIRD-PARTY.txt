第三方组件与许可证

本应用包含 DVD-Audio Maker 的 Rust 实现及若干开源组件。

一、项目本身
  DVD-Audio Maker：GPL-3.0
  许可证全文：LICENSE.txt

二、FFmpeg 媒体库
  FFmpeg 9.0.2：LGPL-2.1-or-later
  libsoxr 0.1.3：LGPL-2.1-or-later
  用途：音频解码、重采样、PCM 检查和菜单 MPEG 生成
  本次构建未启用 GPL-only 组件
  独立许可证全文：FFMPEG-LICENSE.txt

三、图像与字体渲染
  Rust 图像链路：image、rustybuzz、swash
  用途：图像处理、菜单绘制、文字排版
  上游许可：MIT / Apache-2.0，以及部分 BSD、Zlib、Unicode 条款
  完整声明：NOTICE-Image.txt

四、菜单与 author 规则
  菜单行为衍生自 dvdauthor / spumux
  LPCM 打包规则翻译自 dvda-author
  用途：DVD-Video 导航、子画面、LPCM 与 IFO/AOB 规则
  归属与 GPL-2.0-or-later 声明：NOTICE-Menu.txt

五、菜单字体
  DvdaNotoCJK-Regular.ttc
  用途：中文、日文、韩文菜单字形
  许可：SIL Open Font License 1.1

六、分发说明
  发布包不包含 ffmpeg.exe、ffprobe.exe、ImageMagick 命令行程序、eac3to 或外部 MLP 编码器。
  FFmpeg、图像库、菜单字体和 Rust author 均以静态方式集成。
  重新分发或修改时，请保留 LICENSE.txt、FFMPEG-LICENSE.txt、NOTICE-Image.txt、NOTICE-Menu.txt 及本说明，并按各上游许可证提供源码或补丁。
