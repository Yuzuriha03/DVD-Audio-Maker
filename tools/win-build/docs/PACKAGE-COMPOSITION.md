# 发布包组成盘点

本报告只盘点现有 ZIP 和 EXE 内嵌资源，不修改包体。数据来自 `DVD-Audio-Maker-v1.1-win-x64.zip` 与 `DVD-Audio-Maker-v1.1-win-arm64.zip`；内嵌资源按 `DVDRUN01` 元数据中的原始大小和压缩长度统计。

## 内嵌资源（两架构相同）

| 类别 | 原始大小（字节） | 内嵌压缩长度（字节） |
| --- | ---: | ---: |
| 字体 `DvdaNotoCJK-Regular.ttc` | 14,251,880 | 11,757,464 |
| `data/menu` 菜单素材 | 195,801 | 51,157 |
| `type.xml` | 1,383 | 452 |

## 包体构成

| 项目 | x64 | ARM64 |
| --- | ---: | ---: |
| ZIP 总大小 | 16,623,045 B | 16,143,271 B |
| EXE 大小 | 22,213,120 B | 20,578,304 B |
| 字体压缩长度 / EXE | 52.93% | 57.14% |
| 字体压缩长度 / ZIP | 70.73% | 72.83% |
| 菜单素材压缩长度 / EXE | 0.230% | 0.249% |
| 其他 EXE 代码与元数据 | 10,404,047 B（46.84%） | 8,769,231 B（42.61%） |
| 外部文档压缩大小 / ZIP | 53,079 B（0.319%） | 53,079 B（0.329%） |

“其他 EXE 代码与元数据”是 EXE 总大小减去全部内嵌资源压缩长度，包含程序代码及运行时元数据，不能再细分为纯代码大小。

## 结论与边界

- 字体是包体的主要组成：压缩后仍占 ZIP 的约 71%–73%，任何包体优化都应先量化字体收益与动态 CJK 字符覆盖风险。
- 菜单素材不足 EXE 的 0.25%，外部文档不足 ZIP 的 0.33%，不是优先优化对象。
- 本次未进行字体子集化、压缩算法调整、UPX、资源删除或重新打包。
- 结构化数据见被忽略的 `build/benchmarks/package-composition.json`。
