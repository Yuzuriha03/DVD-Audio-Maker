# DVD-Audio Maker

[English](README.en.md) · [日本語](README.ja.md)

适用于 Windows 10/11 x64。解压发布 ZIP，运行 **DVD-Audio-Maker.exe**。

必要组件已内置，首次启动会自动准备，可能比以后稍慢。说明和许可证放在 EXE 旁边。

## 制作光盘

1. 选择 FLAC/M4A 音源文件夹、成品位置和工作文件夹。
2. 设置光盘名称、容量、编码方式，按需启用封面菜单。
3. 点击“检查音源”并处理错误。制作时也会自动检查，未变化的音源可复用有效检查结果。
4. 制作后点击“验证成品”，核对盘内音频、编码文件及对应音源的目标 PCM。
5. 使用支持 DVD-Audio 的刻录软件或播放器打开生成的 ISO。

**MLP 编码**无损压缩 PCM，通常可在同样容量下容纳更多音乐。**LPCM 编码**直接保存未压缩 PCM，通常需要更多空间。两者均不采用有损压缩；主动更改采样率或位深会改变目标 PCM，请按音源和设备需求设置。

**导入已有 MLP**适用于 SurCode MLP 等兼容工具预先编码的文件。请保留对应原音源，并选择 MLP 目录。导入不会重新编码；未知的重采样或位深转换可能使程序无法证明与原音源一致。

设置和语言自动保存到 %LOCALAPPDATA%/DVD-Audio-Maker/settings.json。可用“保存方案”“另存方案”“打开方案”管理 JSON 方案。旧 config.env 不再支持。界面支持中文、English、日本語。

取消后保留工作文件夹，再次制作时可检查并复用已完成光盘。操作日志保存于 %LOCALAPPDATA%/DVD-Audio-Maker/logs，制作日志同时写入工作文件夹的 build.log。遇到问题可“保存详细日志”。
