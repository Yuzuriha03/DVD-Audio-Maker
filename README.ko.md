# DVD-Audio Maker

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

FLAC 및 ALAC/M4A 음악으로 DVD-Audio ISO 이미지를 만드는 프로그램입니다. Windows에서는 단일 EXE로, Android에서는 ARM64 APK로 실행되며 두 플랫폼 모두 동일한 Rust 제작 흐름(음원 검사 → 인코딩 → 디스크 계획 → 메뉴/ISO 제작 → 검증)을 사용합니다. MLP/LPCM 인코딩, 기존 외부 MLP 가져오기, 디스크 자동 분할, 내비게이션 메뉴, 앨범 표지와 완성품 검증을 지원합니다.

## 다운로드 및 설치

### Windows (v1.2, Windows 10 / 11 x64 · ARM64)

1. [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest)에서 PC에 맞는 단일 EXE를 내려받습니다(파일 이름의 `<version>`은 실제 릴리스에 맞게 읽으세요).
   - Intel / AMD PC: `DVD-Audio-Maker-<version>-win-x64.exe`
   - Windows on ARM 기기: `DVD-Audio-Maker-<version>-win-arm64.exe`
2. 내려받은 EXE를 쓰기 가능한 폴더에 두고 더블 클릭해 실행합니다. 압축 해제나 설치가 필요 없습니다. 첫 실행은 내장 구성 요소를 준비하므로 조금 느릴 수 있습니다.
3. 라이선스, FFmpeg LGPL, 타사·이미지·메뉴 고지는 프로그램의 "정보" 창에 내장되어 있습니다.

**시스템 요구 사항:** Windows 10 / 11(x64 또는 ARM64). 필요한 구성 요소가 모두 내장되어 있어 별도 런타임을 설치할 필요가 없습니다. EXE가 있는 폴더에 쓰기 권한이 있어야 하며, ISO와 임시 파일을 위해 완성품과 비슷한 크기의 여유 공간을 준비하세요.

### Android (Android 7.0 이상, ARM64)

1. [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest)에서 `DVD-Audio-Maker-<version>-android-arm64.apk`를 내려받아 설치합니다. 필요하면 브라우저나 파일 관리자에 해당 출처의 앱 설치를 허용하세요.
2. 앱은 파일 접근을 위해 시스템 폴더 선택기를 사용합니다. 음원 폴더와 출력 폴더를 선택하고 각 폴더에 대한 접근을 허용하세요. 모든 파일 접근 권한은 요청하지 않습니다.
3. 작업 중 앱 내부 작업 공간과 완성품 저장 공간이 함께 필요하므로, 기기 저장 공간을 충분히 확보하세요.

## 주요 기능

- FLAC / ALAC(M4A) 음악으로 DVD-Audio ISO 생성
- MLP 무손실 압축 또는 LPCM 비압축 오디오, 기존 외부 MLP 가져오기 지원
- DVD5, DVD9 또는 사용자 지정 용량에 자동 분할
- 트랙 메뉴, 앨범 인덱스, 재생 표지, 내비게이션 메뉴
- **"디스크 만들기" 단일 동작**이 음원 검사, 인코딩, 디스크 제작, 완성품 검증을 자동으로 수행하며, 별도의 "음원 검사"·"완성품 검증" 버튼은 없습니다.
- 중단된 작업 이어서 하기 또는 처음부터 다시 하기
- Windows와 Android가 같은 Rust 제작 경로를 공유

## 빠른 시작

1. **음원 폴더를 선택합니다.** 앨범마다 폴더를 따로 두는 구성을 권장합니다. 하위 폴더를 포함해 `.flac` 및 `.m4a` 파일을 읽습니다.
2. **출력 위치를 선택합니다.** ISO 저장 폴더, 디스크 제목, 용량을 지정합니다. 트랙 순서대로 채우며 다음 앨범이 들어가지 않으면 새 디스크를 시작합니다.
3. **오디오 설정을 선택합니다.** 보통은 "MLP 인코딩"을 선택합니다. 음원과 재생 기기에 맞춰 샘플링 레이트와 비트 깊이를 고르세요. 값을 낮추면 정밀도가 떨어질 수 있고, 높여도 음원에 없는 정보가 생기지는 않습니다.
4. **메뉴를 설정합니다.** 필요에 따라 트랙 메뉴, 앨범 인덱스, 재생 표지를 켭니다. 메뉴용 글꼴은 기본으로 포함되어 있습니다.
5. **제작을 시작합니다.** Windows에서는 "디스크 만들기", Android에서는 "빌드 시작"을 선택합니다. 음원 검사, 인코딩, 디스크 제작, 완성품 검증이 하나의 동작으로 자동 진행됩니다. 검사에 문제가 있으면 그 단계에서 중단되고 로그와 진단 정보가 표시됩니다.
6. 성공 후에는 "출력 열기"로 완성품이 저장된 폴더(Android는 선택한 폴더)를 확인할 수 있습니다.

실패하거나 취소된 작업은 진행 데이터를 보관하거나 삭제할 수 있습니다. 다시 시작할 때 보관된 진행 데이터가 있으면 계속하기와 처음부터 다시 하기 중에서 선택합니다. 성공한 작업은 기본적으로 중간·임시 데이터를 정리하고 최종 완성품만 남깁니다.

## 음원 요구 사항

- **FLAC**과 **ALAC/M4A**(`.m4a`)를 지원합니다.
- 무손실 음원을 권장합니다. 손실 음원은 기존 손실을 그대로 포함하며 다시 인코딩해도 복원되지 않습니다.
- 음원의 샘플링 레이트, 비트 깊이, 채널 수는 출력과 달라도 됩니다. 설정에 따라 변환됩니다.
- 트랙 번호가 포함된 명확한 파일 이름과 앨범, 제목, 아티스트, 트랙, 날짜 태그를 채우면 메뉴와 로그를 더 쉽게 확인할 수 있습니다.
- 앨범 구분과 트랙 정렬은 실제 실행 결과를 기준으로 확인하세요. 태그가 비어 있거나 서로 다르면 표시가 의도와 달라질 수 있습니다.

## 음원 폴더 구성

앨범마다 폴더를 하나씩 두는 구성을 권장합니다.

```text
Music/                            ← 음원 라이브러리 루트
├─ Album A/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  ├─ 03 - Track.m4a
│  └─ cover.jpg                  ← 선택: 앨범 표지
├─ Album B/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  └─ cover.png
└─ Album C/
   ├─ 01 - Track.flac
   └─ 02 - Track.flac
```

- 음원 라이브러리 루트를 지정하면 하위 폴더를 포함해 `.flac`과 `.m4a` 파일을 읽습니다.
- 앨범 폴더 안에 표지를 두세요(`cover.jpg`, `cover.jpeg`, `cover.png`, `cover.webp` 중 하나).
- 앨범 폴더 안에 불필요한 하위 폴더를 더 만들지 마세요.
- 한 앨범 안에서 FLAC과 M4A를 섞을 수 있지만, 앨범마다 한 형식으로 통일하는 것을 권장합니다.
- 출력 폴더는 음원 라이브러리 밖에 두세요.

## 오디오 설정

| 방식 | 저장 방법 | 용량과 제한 | 선택 기준 |
| --- | --- | --- | --- |
| MLP 인코딩 | PCM을 무손실 압축 | 보통 더 작음, 16 / 20 / 24비트 지원 | 공간을 아끼거나 고해상도·다채널 음악을 담을 때 |
| LPCM 인코딩 | PCM을 비압축으로 저장 | 더 큼, 16 / 24비트, 최대 9.6Mb/s | 압축 없이 그대로 저장할 때 |

이미 호환되는 MLP 파일이 있다면 MLP 가져오기 모드를 선택하고 음원 폴더와 같은 구조의 MLP 폴더를 지정하세요.

**같은 샘플링 레이트, 비트 깊이, 채널 구성의 PCM이라면 MLP와 LPCM의 음질은 같습니다.** LPCM이 더 많은 공간을 쓴다고 해서 음질이 좋아지는 것은 아닙니다.

- 출력 비트 깊이: MLP는 16 / 20 / 24비트, LPCM은 16 / 24비트입니다. 20비트는 MLP를 선택하세요.
- 출력이 16비트이고 음원이 16비트보다 높거나 부동 소수점이면 양자화 왜곡을 줄이기 위해 기본으로 TPDF 디더를 추가합니다. 설정에서 끌 수 있습니다. 16비트 이하 음원에는 디더를 추가하지 않습니다.
- 음원 비트 깊이가 출력보다 높으면 변환되며 bit-perfect가 아닙니다. 그대로 유지하려면 음원과 같거나 더 높은 출력 비트 깊이를 선택하세요.
- 샘플링 레이트: 44.1 / 48 / 88.2 / 96kHz는 1~6채널, 176.4 / 192kHz는 모노와 스테레오를 지원합니다.
- LPCM에는 비트레이트 상한이 있습니다. 예를 들어 96kHz / 24비트 / 6채널은 약 13.8Mb/s라 LPCM으로 저장할 수 없습니다. MLP를 선택하거나 설정을 낮추세요.
- 노이즈가 많은 소재는 MLP 스트림 제한을 넘을 수 있습니다. 인코딩에 실패하면 해당 트랙 로그를 확인하고 오디오 형식을 바꿔 다시 시도하세요.

## 메뉴와 표지

- 앨범 폴더에 `cover.jpg`, `cover.jpeg`, `cover.png`, `cover.webp` 중 하나를 두면 표지로 사용됩니다.
- 메뉴에서 트랙 선택, 앨범 인덱스, 재생 표지, 내비게이션 메뉴를 표시할 수 있습니다. 표지가 없으면 검은 배경을 사용합니다.
- 메뉴용 글꼴이 포함되어 있으며 간체 중국어, 번체 중국어, 일본어, 한국어 표시를 지원합니다.

## 작업, 이어서 하기, 로그

### 공통

- 작업이 실패하거나 취소되면 진행 데이터를 보관하거나 삭제할 수 있습니다.
- 다음에 시작할 때 보관된 진행 데이터가 있으면 계속하기와 처음부터 다시 하기 중에서 선택합니다.
- 성공한 작업은 기본적으로 중간·임시 데이터를 정리하고 최종 완성품(ISO 등)은 유지합니다.
- 상세 로그에는 제작 단계와 오류 원인이 기록되며, 문제를 확인할 때 활용하세요.

### Windows 전용

- 설정은 레지스트리가 아니라 EXE 옆의 `settings.json`에 저장되는 포터블 방식입니다.
- 세션 로그는 EXE 옆에 `gui-시간-프로세스ID-순번.log` 형식으로 저장되며 최근 3회만 보관됩니다.
- 상세 로그 보기와 "상세 로그 저장"을 지원합니다.

### Android 전용

- 설정은 앱 내부에 저장되며, 프로필 JSON은 시스템 선택기로 저장하거나 열 수 있습니다. 프로필을 불러와도 폴더 접근 권한은 부여되지 않으므로 기기에서 필요한 폴더를 다시 선택하세요.
- 전체 단일 작업 로그를 파일로 내보낼 수 있습니다.
- 알림과 Live Updates를 지원합니다. Live Updates는 Android 16 이상, 기기·시스템의 지원 여부, 알림 권한 허용 여부에 따라 동작하며, "슈퍼 아일랜드" 등의 기능을 보장하지는 않습니다.
- 캐시 정리 기능은 사용자가 권한을 부여한 폴더나 완성된 ISO를 삭제하지 않습니다.

## 문제 해결

**ISO를 일반 DVD 플레이어에서 재생할 수 있나요?**

보장할 수 없습니다. DVD-Audio를 지원하는 소프트웨어나 기기가 필요합니다. 일반 DVD-Video 플레이어에서는 재생되지 않을 수 있습니다.

**LPCM에서 20비트를 선택할 수 없는 이유는 무엇인가요?**

현재 LPCM은 16 / 24비트만 지원합니다. 20비트로 만들려면 MLP를 선택하세요. LPCM에는 9.6Mb/s 상한도 있습니다.

**"디스크 만들기"가 음원 검사 단계에서 실패합니다.**

표시된 트랙과 이유를 확인하고, 파일을 읽을 수 있는지, FLAC 또는 M4A인지, 태그와 경로에 문제가 없는지 확인한 뒤 다시 실행하세요.

**Android에서 폴더에 접근할 수 없습니다.**

시스템 폴더 선택기로 음원 폴더와 출력 폴더를 다시 선택하고 접근을 허용하세요. 앱은 권한이 부여된 폴더만 읽고 씁니다.

**저장 공간이 부족합니다.**

Android는 앱 내부 작업 공간과 출력 폴더에, Windows는 ISO와 임시 파일에 완성품과 비슷한 크기의 여유 공간이 필요합니다. 공간을 확보한 뒤 다시 실행하세요.
