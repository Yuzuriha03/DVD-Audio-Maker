# DVD-Audio Maker

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

FLAC 및 ALAC/M4A 음악으로 DVD-Audio ISO 이미지를 만드는 Windows용 프로그램입니다. MLP / LPCM 인코딩, 디스크 자동 분할, 트랙 메뉴, 앨범 표지, 완성품 검증을 지원합니다. ZIP 압축을 풀고 EXE를 실행하면 되며 별도 설치가 필요 없습니다.

## 다운로드 및 설치

1. [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest)를 열고 PC에 맞는 패키지를 내려받습니다.
   - 일반 Intel / AMD PC: `DVD-Audio-Maker-v1.1-win-x64.zip`
   - Windows on ARM 기기: `DVD-Audio-Maker-v1.1-win-arm64.zip`
2. ZIP 압축을 원하는 폴더에 풀고 `DVD-Audio-Maker.exe`를 더블 클릭합니다.
3. 압축을 푼 폴더의 `LICENSE`, `THIRD-PARTY.md`, `THIRD-PARTY.en.md`, `NOTICE-Image.txt`, `NOTICE-Menu.txt` 파일은 보관하세요.

**시스템 요구 사항:** Windows 10 / 11(x64 또는 ARM64). 필요한 구성 요소가 모두 내장되어 있어 별도 런타임을 설치할 필요가 없습니다. EXE가 있는 폴더에 쓰기 권한이 있어야 합니다. ISO와 임시 파일을 위해 완성품과 비슷한 크기의 여유 공간을 준비하세요.

## 주요 기능

- FLAC / ALAC/M4A 음악으로 DVD-Audio ISO 생성
- MLP 무손실 압축 또는 LPCM 비압축 오디오
- DVD5, DVD9 또는 사용자 지정 용량에 자동 분할하며 앨범은 나누지 않음
- 트랙 메뉴, 앨범 인덱스, 재생 표지
- 제작 전 음원 검사와 제작 후 완성품 검증
- 중단된 작업 이어서 하기
- 설정을 프로그램 폴더에 저장하는 포터블 방식(레지스트리 사용 안 함)

## 빠른 시작

1. **음원 폴더를 선택합니다.** 앨범마다 폴더를 따로 두는 것이 좋습니다. 하위 폴더를 포함해 `.flac` 및 `.m4a` 파일을 읽습니다. 앨범, 제목, 트랙 번호, 날짜 태그를 채워 두세요.
2. **출력 위치를 선택합니다.** ISO 저장 폴더, 디스크 제목, 용량을 지정합니다. 트랙 순서대로 채우며 다음 앨범이 들어가지 않으면 새 디스크를 시작합니다.
3. **오디오 설정을 선택합니다.** 보통은 "MLP 인코딩"을 선택합니다. 음원과 재생 기기에 맞춰 샘플링 레이트와 비트 깊이를 고르세요. 값을 낮추면 정밀도가 떨어질 수 있고, 높여도 음원에 없는 정보가 생기지는 않습니다.
4. **메뉴를 설정합니다.** 필요에 따라 트랙 메뉴, 앨범 인덱스, 재생 표지를 켭니다. 메뉴용 글꼴은 기본으로 포함되어 있습니다.
5. **"음원 검사"**를 클릭하고 표시되는 문제를 해결합니다.
6. **"디스크 만들기"**를 클릭하면 인코딩과 ISO 생성이 시작됩니다.
7. 완료 후 **"완성품 검증"**을 실행합니다. 통과하면 "출력 열기"로 ISO 폴더를 열 수 있습니다.

"디스크 만들기"는 음원을 자동으로 검사하며, 검사에 실패하면 제작을 중단합니다. 작업 중 취소할 수 있으며, 취소해도 이미 완성된 출력은 삭제되지 않습니다.

## 음원 요구 사항

- **FLAC**과 **ALAC/M4A**(`.m4a`)를 지원합니다.
- 무손실 음원을 권장합니다. 손실 음원은 기존 손실을 그대로 포함하며 다시 인코딩해도 복원되지 않습니다.
- 음원의 샘플링 레이트, 비트 깊이, 채널 수는 출력과 달라도 됩니다. 설정에 따라 변환됩니다.
- 트랙 번호가 포함된 명확한 파일 이름과 앨범, 제목, 아티스트, 트랙, 날짜 태그를 채우면 메뉴와 로그를 더 쉽게 확인할 수 있습니다.

## 음원 폴더 구성

앨범마다 폴더를 하나씩 두는 구성을 권장합니다.

```text
Music/                            ← DVDA_SRC
├─ Album A/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  ├─ 03 - Track.m4a
│  └─ cover.jpg                  ← 선택: 앨범 표지
├─ Album B/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  └─ cover.png
└─ Album C/
   ├─ 01 - Track.flac
   └─ 02 - Track.flac
```

- `DVDA_SRC`는 음악 라이브러리 루트를 가리키며, 하위 폴더를 포함해 `.flac`과 `.m4a` 파일을 읽습니다.
- **앨범은 `Album` 태그로 묶이며 폴더 이름만으로 결정되지 않습니다.** 같은 앨범의 모든 트랙에서 Album 태그를 동일하게 맞추세요. 태그가 비어 있거나 서로 다르면 앨범이 합쳐지거나 나뉠 수 있습니다.
- 파일 이름은 `01 - Track.flac`처럼 지정하고 `Track` 태그도 함께 채우세요. 파일 이름 순서로 읽으며, 태그는 표시와 정렬에 사용됩니다.
- 앨범 폴더 안에 하위 폴더를 더 만들지 마세요. 표지는 앨범 폴더 바로 아래에 두세요.
- 한 앨범 안에서 FLAC과 M4A를 섞을 수 있지만, 앨범마다 한 형식으로 통일하는 것을 권장합니다.
- 출력 폴더(`DVDA_FINAL_DIR`)는 음악 라이브러리 밖에 두세요.

JSON 설정에서는 다음 키에 해당합니다.

```json
"DVDA_SRC": "D:/Music/MyAlbums",
"DVDA_FINAL_DIR": "D:/DVD-Audio/Output"
```

화면의 "음원 폴더"가 `DVDA_SRC`, "출력 위치"가 `DVDA_FINAL_DIR`에 해당합니다.

## 오디오 설정

| 방식 | 저장 방법 | 용량과 제한 | 선택 기준 |
| --- | --- | --- | --- |
| MLP 인코딩 | PCM을 무손실 압축 | 보통 더 작음, 16 / 20 / 24비트 지원 | 공간을 아끼거나 고해상도·다채널 음악을 담을 때 |
| LPCM 인코딩 | PCM을 비압축으로 저장 | 더 큼, 16 / 24비트, 최대 9.6Mb/s | 압축 없이 그대로 저장할 때 |

**같은 샘플링 레이트, 비트 깊이, 채널 구성의 PCM이라면 MLP와 LPCM의 음질은 같습니다.** LPCM이 더 많은 공간을 쓴다고 해서 음질이 좋아지는 것은 아닙니다.

- 출력 비트 깊이: MLP는 16 / 20 / 24비트, LPCM은 16 / 24비트입니다. 20비트는 MLP를 선택하세요.
- 출력이 16비트이고 음원이 16비트보다 높거나 부동 소수점이면 양자화 왜곡을 줄이기 위해 기본으로 TPDF 디더를 추가합니다. 설정에서 끌 수 있습니다. 16비트 이하 음원에는 디더를 추가하지 않습니다.
- 음원 비트 깊이가 출력보다 높으면 변환되며 bit-perfect가 아닙니다. 그대로 유지하려면 음원과 같거나 더 높은 출력 비트 깊이를 선택하세요.
- 샘플링 레이트: 44.1 / 48 / 88.2 / 96kHz는 1~6채널, 176.4 / 192kHz는 모노와 스테레오를 지원합니다.
- LPCM에는 비트레이트 상한이 있습니다. 예를 들어 96kHz / 24비트 / 6채널은 약 13.8Mb/s라 LPCM으로 저장할 수 없습니다. MLP를 선택하거나 설정을 낮추세요.
- 노이즈가 많은 소재는 MLP 스트림 제한을 넘을 수 있습니다. 인코딩에 실패하면 해당 트랙 로그를 확인하고 오디오 형식을 바꿔 다시 시도하세요.

## 메뉴와 표지

- 앨범 폴더에 `cover.jpg`, `cover.jpeg`, `cover.png`, `cover.webp` 중 하나를 두면 표지로 사용됩니다.
- 메뉴에서 트랙 선택, 앨범 인덱스, 재생 표지를 표시할 수 있습니다. 표지가 없으면 검은 배경을 사용합니다.
- 메뉴용 글꼴이 포함되어 있으며 간체 중국어, 번체 중국어, 일본어, 한국어 표시를 지원합니다.

## 작업, 이어서 하기, 로그

- 기본적으로 시스템 임시 폴더를 사용하며 성공, 실패 또는 정상 취소 후 작업 데이터를 삭제하고 완성된 ISO만 남깁니다.
- "미완성 작업 이어서 하기"를 선택하면 선택한 작업 폴더의 `unfinished-task`에 미완성 작업을 보관하고 다음 실행 시 이어서 할 수 있습니다. 제작과 검증이 성공하면 삭제됩니다.
- 세션 로그는 EXE 옆에 `gui-시간-프로세스ID-순번.log`로 저장되며 최근 3회만 보관됩니다.
- 문제를 확인할 때는 상세 로그로 전환하거나 "상세 로그 저장"을 실행하세요.

## 자주 묻는 질문

**ISO를 일반 DVD 플레이어에서 재생할 수 있나요?**  
보장할 수 없습니다. DVD-Audio를 지원하는 소프트웨어나 기기가 필요합니다. 일반 DVD-Video 플레이어에서는 재생되지 않을 수 있습니다.

**LPCM에서 20비트를 선택할 수 없는 이유는 무엇인가요?**  
현재 LPCM은 16 / 24비트만 지원합니다. 20비트로 만들려면 MLP를 선택하세요. LPCM에는 9.6Mb/s 상한도 있습니다.

**"음원 검사"에 실패합니다.**  
표시된 트랙과 이유를 확인하고, 파일을 읽을 수 있는지, FLAC 또는 M4A인지, 태그와 경로에 문제가 없는지 확인하세요. 수정한 뒤 다시 검사하세요. 검사 결과는 작업 간에 캐시되지 않습니다.

**제작 또는 검증에 실패합니다.**  
상세 로그와 작업 폴더를 보관하고 여유 공간, 쓰기 권한, 음원 상태를 확인한 뒤 다시 시도하세요. ISO가 생성되었다고 해서 검증을 마친 것은 아닙니다.

**설정은 어디에 저장되나요?**  
EXE와 같은 폴더의 `settings.json`에 저장하고 시작할 때 읽습니다. `%LOCALAPPDATA%`에는 쓰지 않습니다. 해당 폴더에 쓰기 권한이 필요합니다. "설정 저장"과 "설정 열기"로 JSON 프로필을 관리할 수 있습니다.

**삭제하려면 어떻게 하나요?**  
프로그램 폴더를 삭제하면 됩니다. 레지스트리는 사용하지 않습니다. 필요한 ISO와 로그는 먼저 다른 곳으로 옮기세요.

## 인터페이스 언어

화면과 로그는 간체 중국어, 번체 중국어, 영어, 일본어, 한국어를 지원합니다. 마지막으로 선택한 언어를 기억하며 직접 전환할 수도 있습니다.
