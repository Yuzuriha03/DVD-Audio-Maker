# DVD-Audio Maker

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

FLAC と ALAC/M4A の音楽から DVD-Audio ISO イメージを作成する Windows アプリです。MLP / LPCM エンコード、ディスクへの自動振り分け、選曲メニュー、アルバム画像、完成品の検証に対応しています。ZIP を展開して EXE を起動するだけで使え、インストールは不要です。

## ダウンロードと起動

1. [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest) を開き、お使いの PC に合うパッケージをダウンロードします。
   - Intel / AMD の PC：`DVD-Audio-Maker-v1.1-win-x64.zip`
   - Windows on ARM デバイス：`DVD-Audio-Maker-v1.1-win-arm64.zip`
2. ZIP を任意のフォルダーに展開し、`DVD-Audio-Maker.exe` をダブルクリックします。
3. 展開先の `LICENSE`、`THIRD-PARTY.md`、`THIRD-PARTY.en.md`、`NOTICE-Image.txt`、`NOTICE-Menu.txt` は保管してください。

**動作環境：** Windows 10 / 11（x64 または ARM64）。必要なコンポーネントはすべて内蔵されているため、別途ランタイムをインストールする必要はありません。EXE を置いたフォルダーには書き込み権限が必要です。ISO と一時ファイル用に、完成品と同程度の空き容量を用意してください。

## 主な機能

- FLAC / ALAC/M4A から DVD-Audio ISO を作成
- MLP 可逆圧縮または LPCM 非圧縮で収録
- DVD5 / DVD9 / 任意の容量に自動で振り分け、アルバムは分割しない
- 選曲メニュー、アルバム一覧、再生中のカバー画像
- 作成前の音源検査と、作成後の完成品検証
- 中断した作成を再開
- 設定はアプリと同じフォルダーに保存するポータブル方式（レジストリ不使用）

## はじめかた

1. **音源フォルダーを選択します。** アルバムごとにフォルダーを分けてください。`.flac` と `.m4a` をサブフォルダーも含めて読み込みます。アルバム名、曲名、曲番号、日付などのタグを入れておくと便利です。
2. **出力先を選択します。** ISO の保存先、ディスク名、容量を指定します。曲順に収録し、次のアルバムが入らない場合は自動で次のディスクを開始します。
3. **音声設定を選びます。** 通常は「MLP エンコード」を選びます。音源と再生機器に合わせてサンプリング周波数とビット深度を設定してください。値を下げると精度が失われる場合があり、上げても音源にない情報は増えません。
4. **メニューを設定します。** 必要に応じて選曲メニュー、アルバム一覧、再生中のカバーを有効にします。メニュー用フォントは付属しています。
5. **「音源を検査」** をクリックし、表示された問題を解決します。
6. **「ディスクを作成」** をクリックすると、エンコードと ISO の作成が始まります。
7. 完了後に **「完成品を検証」** を実行します。成功したら「出力を開く」で ISO のフォルダーを開けます。

「ディスクを作成」は音源を自動で検査し、失敗した場合は作成を中止します。作成中はキャンセルできます。キャンセルしても完成済みの出力は削除されません。

## 音源について

- **FLAC** と **ALAC/M4A**（`.m4a`）に対応しています。
- 可逆圧縮の音源を推奨します。非可逆音源は元の損失をそのまま含み、再エンコードしても失われた情報は戻りません。
- 音源のサンプリング周波数、ビット深度、チャンネル数は出力と異なっていてもかまいません。設定に従って変換されます。
- 曲番号を含む分かりやすいファイル名と、アルバム・曲名・アーティスト・曲番号・日付などのタグを付けてください。

## 音源フォルダーの構成

アルバムごとにフォルダーを分けて音楽ライブラリを整理することをおすすめします。

```text
Music/                            ← DVDA_SRC
├─ Album A/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  ├─ 03 - Track.m4a
│  └─ cover.jpg                  ← 任意：アルバム画像
├─ Album B/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  └─ cover.png
└─ Album C/
   ├─ 01 - Track.flac
   └─ 02 - Track.flac
```

- `DVDA_SRC` は音楽ライブラリのルートを指します。`.flac` と `.m4a` をサブフォルダーも含めて読み込みます。
- **アルバムは `Album` タグでまとめられます。フォルダー名だけでは決まりません。** 同じアルバムの全曲で Album タグをそろえてください。空または不一致の場合、別アルバムが統合されたり、同じアルバムが分割されたりすることがあります。
- 曲名は `01 - 曲名.flac` のようにし、`Track` タグも入力してください。ファイル名順に読み込み、タグは表示と並び順に使われます。
- アルバムフォルダーの中にさらにサブフォルダーを作らないでください。カバー画像はアルバムフォルダーの直下に置きます。
- 同じアルバムで FLAC と M4A を混在させられますが、アルバム単位で形式をそろえることをおすすめします。
- 出力フォルダー（`DVDA_FINAL_DIR`）は音楽ライブラリの外に置いてください。

JSON 設定では次のキーに対応します。

```json
"DVDA_SRC": "D:/Music/MyAlbums",
"DVDA_FINAL_DIR": "D:/DVD-Audio/Output"
```

画面の「音源フォルダー」が `DVDA_SRC`、「出力先」が `DVDA_FINAL_DIR` に対応します。

## 音声設定

| 方式 | 保存方法 | 容量と制限 | 選ぶ目安 |
| --- | --- | --- | --- |
| MLP エンコード | PCM を可逆圧縮 | 通常は小さめ。16 / 20 / 24 ビットに対応 | 容量を抑えたい場合や、高解像度・多チャンネルを収録する場合 |
| LPCM エンコード | PCM を非圧縮で収録 | 大きめ。16 / 24 ビット、最大 9.6 Mb/s | 非圧縮のまま収録したい場合 |

**同じサンプリング周波数・ビット深度・チャンネル構成の PCM では、MLP と LPCM の音質は同じです。** LPCM の方が高音質になるわけではありません。

- 出力ビット深度：MLP は 16 / 20 / 24 ビット、LPCM は 16 / 24 ビットです。20 ビットは MLP を選んでください。
- 出力が 16 ビットで、音源が 16 ビットより高い、または浮動小数点の場合は、量子化歪みを抑えるため TPDF ディザを既定で追加します。設定で無効にできます。16 ビット以下の音源にはディザを追加しません。
- 音源のビット深度が出力より高い場合は変換され、bit-perfect にはなりません。そのまま保ちたい場合は、音源と同じかそれ以上の出力ビット深度を選んでください。
- サンプリング周波数：44.1 / 48 / 88.2 / 96 kHz は 1～6 チャンネル、176.4 / 192 kHz はモノラルとステレオに対応します。
- LPCM にはビットレート上限があります。例えば 96 kHz / 24 ビット / 6 チャンネルは約 13.8 Mb/s となり LPCM では収録できません。MLP を選ぶか設定を下げてください。
- ノイズの多い素材では MLP のストリーム制限を超える場合があります。失敗した曲のログを確認し、音声形式を変えて再試行してください。

## メニューとカバー画像

- アルバムフォルダーに `cover.jpg`、`cover.jpeg`、`cover.png`、`cover.webp` のいずれかを置くとカバーとして使われます。
- メニューでは選曲、アルバム一覧、再生中のカバーを表示できます。カバーがない場合は黒背景になります。
- メニュー用フォントは付属しており、簡体字中国語・繁体字中国語・日本語・韓国語に対応します。

## タスク・再開・ログ

- 通常はシステムの一時フォルダーを使い、成功・失敗・通常のキャンセル後にタスクデータを削除します。残るのは出力済みの ISO だけです。
- 「未完了の作業を再開」を有効にすると、選択した作業フォルダーの `unfinished-task` に未完了データを保持し、次回起動時に再開できます。作成と検証の成功後は削除されます。
- セッションログは EXE と同じフォルダーに `gui-時刻-プロセスID-連番.log` として保存され、直近 3 回分のみ保持されます。
- 問題を調べるときは詳細ログに切り替えるか、「詳細ログを保存」を実行してください。

## よくある質問

**ISO を普通の DVD プレーヤーで再生できますか？**  
保証はできません。DVD-Audio に対応したソフトウェアまたは機器が必要です。通常の DVD-Video プレーヤーでは再生できない場合があります。

**LPCM で 20 ビットを選べないのはなぜですか？**  
現在の LPCM は 16 / 24 ビットのみ対応しています。20 ビットにしたい場合は MLP を選んでください。LPCM には 9.6 Mb/s の上限もあります。

**「音源を検査」に失敗します。**  
表示された曲と理由を確認し、ファイルが読み取れること、FLAC または M4A であること、タグとパスに問題がないことを確認してください。修正後に再検査してください。検査結果はタスク間でキャッシュされません。

**作成または検証に失敗します。**  
詳細ログと作業フォルダーを保存し、空き容量、書き込み権限、音源の状態を確認してから再試行してください。ISO ができただけでは検証完了ではありません。

**設定はどこに保存されますか？**  
EXE と同じフォルダーの `settings.json` に保存し、起動時に読み込みます。`%LOCALAPPDATA%` には保存しません。フォルダーには書き込み権限が必要です。「設定を保存」「設定を開く」で JSON プロファイルを管理できます。

**アンインストールするには？**  
アプリのフォルダーを削除してください。レジストリは使用しません。必要な ISO やログは先に別の場所へ移動してください。

## 表示言語

画面とログは簡体字中国語、繁体字中国語、英語、日本語、韓国語に対応しています。最後に選んだ言語を記憶し、手動で切り替えることもできます。
