# DVD-Audio Maker

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

Windows（x64 / ARM64）の単一 EXE と Android（ARM64）の APK で、FLAC / ALAC(M4A) の音楽から DVD-Audio ISO を作成します。MLP / LPCM エンコード、自動分盤、ナビゲーションメニュー、アルバム画像、完成品の検証に対応しています。Windows 版はダウンロードした EXE を実行するだけで、インストールも解凍も不要です。

## ダウンロードとインストール

### Windows 版

1. [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest) を開き、お使いの PC に合う単一 EXE をダウンロードします（ファイル名の `<バージョン>` は実際のリリースに合わせて読み替えてください）。
   - Intel / AMD の PC：`DVD-Audio-Maker-<バージョン>-win-x64.exe`
   - Windows on ARM デバイス：`DVD-Audio-Maker-<バージョン>-win-arm64.exe`
2. EXE を書き込み可能なフォルダーに置き、そのままダブルクリックして起動します。解凍やインストールは不要です。初回起動時は内蔵コンポーネントの準備のため少し時間がかかります。
3. ライセンス、FFmpeg の LGPL 表示、第三者・画像・メニューの各声明はプログラムの「情報」画面に内蔵されています。

**動作環境（Windows）：** Windows 10 / 11（x64 または ARM64）。必要なコンポーネントは内蔵されているため、別途ランタイムをインストールする必要はありません。EXE を置いたフォルダーには書き込み権限が必要です。ISO と一時ファイル用に、完成品と同程度の空き容量を用意してください。

### Android 版

1. [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/latest) から ARM64 用の APK（`DVD-Audio-Maker-<バージョン>-android-arm64.apk`）をダウンロードします。
2. Android 7.0 以上の ARM64 端末にインストールします。端末の設定で提供元不明のアプリのインストールを許可する必要がある場合があります。
3. 起動後、システムのファイル選択画面で音源フォルダーと出力先を指定します。アプリは「すべてのファイルへのアクセス」権限を要求せず、選択したフォルダーへのアクセス許可だけを取得します。アプリ内部の作業領域と出力先に、制作に十分な空き容量を確保してください。

## 主な機能

- FLAC / ALAC(M4A) から DVD-Audio ISO を作成
- MLP 可逆圧縮または LPCM 非圧縮で収録
- 既存の外部 MLP ファイルのインポート
- DVD5 / DVD9 / 任意の容量への自動分盤
- ナビゲーションメニュー（アルバム索引＋曲目ページ）、再生中のカバー画像
- Windows と Android は同じ Rust 実装の制作フローを共有
- 中断した制作の再開
- Windows は単一 EXE、Android は APK で提供

## はじめかた

1. **音源フォルダーを選択します。** FLAC または ALAC/M4A のファイルを含むフォルダーを指定します。アルバム、曲名、曲番号、日付などのタグを入れておくと、メニューやログが分かりやすくなります。
2. **出力先とディスク設定を指定します。** ISO の保存先、ディスク名、容量を設定します。
3. **音声設定を選びます。** 通常は「MLP エンコード」を選びます。音源と再生機器に合わせてサンプリング周波数とビット深度を設定してください。
4. **メニューを設定します。** 必要に応じてナビゲーションメニュー、アルバム索引、再生中のカバーを有効にします。メニュー用フォントは内蔵されています。
5. **制作を開始します。** Windows の「ディスクを作成」、Android の「制作を開始」を 1 回実行すると、音源チェック、エンコード、ISO の作成、完成品の検証までが自動で進みます。独立した「音源を検査」「完成品を検証」ボタンはありません。
6. 成功したら「出力を開く」（Android では「成品を開く」）で ISO のフォルダーを開けます。

制作中はキャンセルできます。失敗またはキャンセル後は、進捗を保持するか削除するかを選択できます。次に制作を開始したときは、続きから再開するか最初からやり直すかを選択できます。制作と検証に成功した場合は、既定で中間データを削除します。

## 音源について

- **FLAC** と **ALAC/M4A**（`.m4a`）に対応しています。圧縮された `cmov` atom を使う一部の MOV/M4A には対応していません。通常の M4A/ALAC は使用できます。
- 可逆圧縮の音源を推奨します。非可逆音源は元の損失をそのまま含み、再エンコードしても失われた情報は戻りません。
- 音源のサンプリング周波数、ビット深度、チャンネル数は出力と異なっていてもかまいません。設定に従って変換されます。
- 曲番号を含む分かりやすいファイル名と、アルバム・曲名・アーティスト・曲番号・日付などのタグを付けてください。

## 音源フォルダーの構成

アルバムごとにフォルダーを分けると管理しやすくなります。

```text
Music/                            ← DVDA_SRC
├─ Album A/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  ├─ 03 - Track.m4a
│  └─ cover.jpg                  ← 任意：アルバム画像
├─ Album B/
│  ├─ 01 - Track.flac
│  ├─ 02 - Track.flac
│  └─ cover.png
└─ Album C/
   ├─ 01 - Track.flac
   └─ 02 - Track.flac
```

- `DVDA_SRC` は音楽ライブラリのルート、`DVDA_FINAL_DIR` は ISO の出力先に対応します。
- 出力先は音源フォルダーとは別の場所にすることをおすすめします。
- 同じアルバムの曲には同じ `Album` タグを付け、ファイル名と `Track` タグに曲番号を入れてください。

## 音声設定

| 方式 | 保存方法 | 容量と制限 | 選ぶ目安 |
| --- | --- | --- | --- |
| MLP エンコード | PCM を可逆圧縮 | 通常は小さめ。16 / 20 / 24 ビットに対応 | 容量を抑えたい場合や、高解像度・多チャンネルを収録する場合 |
| LPCM エンコード | PCM を非圧縮で収録 | 大きめ。16 / 24 ビット、最大 9.6 Mb/s | 非圧縮のまま収録したい場合 |

**同じサンプリング周波数・ビット深度・チャンネル構成の PCM では、MLP と LPCM の音質は同じです。** LPCM の方が高音質になるわけではありません。

- 出力ビット深度：MLP は 16 / 20 / 24 ビット、LPCM は 16 / 24 ビットです。20 ビットは MLP を選んでください。
- 出力が 16 ビットで、音源が 16 ビットより高い、または浮動小数点の場合は、量子化歪みを抑えるため TPDF ディザを既定で追加します。設定で無効にできます。16 ビット以下の音源にはディザを追加しません。
- 音源のビット深度が出力より高い場合は変換され、bit-perfect にはなりません。そのまま保ちたい場合は、音源と同じかそれ以上の出力ビット深度を選んでください。
- サンプリング周波数：44.1 / 48 / 88.2 / 96 kHz は 1～6 チャンネル、176.4 / 192 kHz はモノラルとステレオに対応します。
- LPCM にはビットレート上限があります。例えば 96 kHz / 24 ビット / 6 チャンネルは約 13.8 Mb/s となり LPCM では収録できません。MLP を選ぶか設定を下げてください。
- ノイズの多い素材では MLP のストリーム制限を超える場合があります。失敗した曲のログを確認し、音声形式を変えて再試行してください。

## ナビゲーションメニューとカバー画像

- アルバムフォルダーに `cover.jpg`、`cover.jpeg`、`cover.png`、`cover.webp` のいずれかを置くとカバーとして使われます。
- メニューではアルバム索引と曲目ページ、再生中のカバーを表示できます。カバーがない場合は黒背景になります。
- メニュー用フォントは内蔵されており、簡体字中国語・繁体字中国語・日本語・韓国語に対応します。

## タスク、再開、ログ、設定

- 制作中は進捗が表示され、キャンセルできます。失敗またはキャンセル後は、進捗を保持するか削除するかを選択できます。
- 未完了の制作がある状態で制作を開始すると、続きから再開するか最初からやり直すかを選択できます。
- 制作と検証に成功した場合は、既定で中間データを削除します。

### Windows 版

- セッションログは EXE と同じフォルダーに `gui-日時-プロセスID-連番.log` として保存され、直近 3 回分のみ保持されます。問題を調べるときは詳細ログに切り替えるか、「詳細ログを保存」を実行してください。
- 設定は EXE と同じフォルダーの `settings.json` に保存され、起動時に読み込まれます。`%LOCALAPPDATA%` には保存しません。EXE のフォルダーには書き込み権限が必要です。
- GUI の「プロファイルを保存」「プロファイルを開く」から JSON 形式の設定を保存・読み込みできます。

### Android 版

- 音源フォルダーと出力先は、システムのファイル選択画面で指定します。「すべてのファイルへのアクセス」権限は要求しません。
- 普段の設定はアプリ内部に保存されます。JSON プロファイルの保存と読み込みにはシステムのファイル選択画面を使います。プロファイルを読み込んでもフォルダーの権限は付与されないため、端末で選び直してください。
- ログは問題のみの表示、コピー、システムのファイル選択画面からの書き出しに対応しています。タスク 1 回分のログ全体をファイルとして保存できます。
- 制作中は通知領域に進捗を表示します。Android 16 以降で、端末が対応し通知権限が許可されている場合は Live Updates 形式の進捗通知を利用できます。メーカー独自の拡張表示（スーパーアイランドなど）は保証しません。
- 「進捗を削除」やキャッシュの整理は、アプリ内部のキャッシュと未完了タスクだけを対象とします。システムのファイル選択画面で許可したフォルダーや、書き出し済みの ISO は削除しません。

## よくある質問

**ISO を普通の DVD プレーヤーで再生できますか？**

保証はできません。DVD-Audio に対応したソフトウェアまたは機器が必要です。通常の DVD-Video プレーヤーでは再生できない場合があります。

**LPCM で 20 ビットを選べないのはなぜですか？**

現在の LPCM は 16 / 24 ビットのみ対応しています。20 ビットにしたい場合は MLP を選んでください。LPCM には 9.6 Mb/s の上限もあります。

**制作または検証に失敗した場合は？**

詳細ログと制作時の設定を確認し、空き容量、出力先の書き込み権限、音源の状態を確認してから再試行してください。ISO ができただけでは検証完了ではありません。未完了の制作がある場合は、次回開始時に続きから再開できます。

**設定はどこに保存されますか？**

Windows 版は EXE と同じフォルダーの `settings.json`、Android 版はアプリ内部に保存します。両方の版で JSON プロファイルを別途保存・読み込みできます。

**アンインストールするには？**

Windows 版はアプリのフォルダーを削除してください。Android 版は通常のアプリの削除操作を行ってください。必要な ISO やログは先に別の場所へ移動してください。
