# DVD-Audio Maker

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

FLAC、ALAC/M4A の音楽から DVD-Audio ISO イメージを作成します。MLP / LPCM エンコード、ディスクへの自動振り分け、選曲メニュー、アルバム画像、完成品の検証に対応しています。Windows x64 用で、画面とログは中国語・英語・日本語に切り替えられます。

**初回起動前に [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/download/dotnet/10.0) をインストールしてください。** 配布パッケージに .NET は含まれません。通常の .NET Runtime、ASP.NET Core Runtime、.NET Framework では代用できません。

## インストールと起動

1. `DVD-Audio-Maker-v1.0-win-x64.zip` を [GitHub Releases](https://github.com/Yuzuriha03/DVD-Audio-Maker/releases/tag/v1.0) からダウンロードします。
2. ZIP を任意のフォルダーに展開し、`DVD-Audio-Maker.exe` をダブルクリックします。
3. 初回は必要なコンポーネントを準備するため、少し時間がかかります。FFmpeg、ImageMagick、eac3to、SurCode の別途インストールは不要です。

プログラム、説明書、設定例、ライセンスは同じフォルダーにあります。`LICENSE`、`THIRD-PARTY.md`、`THIRD-PARTY.en.md`、`NOTICE-Image.txt`、`NOTICE-Menu.txt` は保管してください。

## 最初のディスクを作成する

1. **音源を選択します。** 音楽のフォルダーを選択すると、サブフォルダーも読み込みます。アルバムごとにフォルダーを分け、アルバム名、曲名、曲番号、日付のタグを付けることをおすすめします。
2. **出力先を選択します。** ISO の保存先、ディスク名、DVD5 / DVD9 / 任意の容量を指定します。最大ディスク枚数の 0 は上限なしです。
3. **音声方式を選択します。** 容量を節約するなら「MLP エンコード」、非圧縮で収録するなら「LPCM エンコード」を選びます。サンプリング周波数とビット深度は音源と再生機器に合わせてください。
4. **メニューを設定します。** 必要に応じて選曲メニュー、アルバム一覧、再生中の画像を有効にします。JPG、PNG、WebP に対応し、中日韓のメニューフォントが付属します。
5. **「音源を確認」** で問題を確認し、**「作成開始」** をクリックします。作成開始時も音源を自動確認します。
6. 完成後は **「完成品を検証」** を実行します。「出力フォルダー」から ISO の保存先を開けます。

直前に音源を確認し、ファイル・設定・準備マニフェストが変わっていなければ、「作成開始」は同じ確認結果を再利用します。音源ファイルが変わった場合は自動的に再確認します。

作成は停止できます。処理中にウィンドウを閉じると、現在の処理を停止して一時ファイルを整理します。完成済みの出力は削除しません。書き込みや再生には DVD-Audio 対応のソフトウェアや機器が必要です。通常の DVD-Video プレーヤーでの再生を保証するものではありません。

## MLP と LPCM の違い

| 方式 | 保存方法 | 容量と制限 | 選ぶ目安 |
| --- | --- | --- | --- |
| MLP エンコード | PCM を可逆圧縮 | 通常は LPCM より小さく、16 / 20 / 24 ビットに対応 | 高解像度や多チャンネルの音楽を容量を抑えて収録したい場合 |
| LPCM エンコード | PCM を非圧縮で収録 | 容量が大きく、このアプリでは 16 / 24 ビット、最大 9.6 Mb/s | 圧縮処理なしで音声を収録したい場合 |

**同じサンプリング周波数・ビット深度・チャンネル構成の PCM を使う限り、MLP と LPCM の音声品質は同じです。** LPCM の方が高音質になるわけではありません。周波数やビット深度を下げると音源の精度が失われる場合があり、上げても元の音源にない情報は増えません。

- 44.1 / 48 / 88.2 / 96 kHz は最大 6 チャンネル、176.4 / 192 kHz は最大 2 チャンネルです。LPCM はさらに上記のビットレート制限を満たす必要があります。
- 例えば 96 kHz / 24 ビット / 6 チャンネルの LPCM は 13.824 Mb/s となり、上限を超えます。MLP を選ぶか、出力形式を下げてください。
- LPCM の 20 ビットは現在選択できません。20 ビットの出力には MLP を使用してください。
- MLP でもノイズの多い素材などはストリームの制限を超える場合があります。該当する曲のログを確認してください。
- **既存の MLP を読み込む：** 原版の SurCode MLP（surcodemlp.exe）でエンコードした MLP ファイルを取り込む場合に使います。対応する音源とアルバムフォルダー・ファイル名をそろえてください。既存のファイルをそのまま使用するため、再エンコードや SurCode MLP の起動は行いません。音源の確認と無損失検証のため、元の音源とサンプリング周波数・ビット深度などのエンコード設定を保管してください。読み込みに成功しただけでは、作成元や変換設定が不明なファイルの一致を確認したことにはなりません。

作業フォルダーには検証記録、音声キャッシュ、作成途中のファイルを保存します。特に LPCM は多くの空き容量が必要です。完成品の検証が終わるまで、対応する作業フォルダーを保管してください。

## 設定と言語

画面上で設定を変更し、「設定を保存」で JSON ファイルに保存できます。「設定を開く」で再利用できます。通常の設定は `%LOCALAPPDATA%/DVD-Audio-Maker/settings.json` に自動保存されます。

既存の `config.env` は「旧設定を読み込む…」から読み込めます。保存済みの設定がない場合、EXE の隣または現在の作業フォルダーにある `config.env` も検索します。読み込みで元のファイルを書き換えることはありません。旧 SurCode 読み込みの指定は、汎用の MLP 読み込みとして扱います。

付属の `config.env.example` は任意の参考例です。自動では読み込みません。初めて使う場合は編集不要です。右上の **「中文 / English / 日本語」** で言語を切り替えられます。言語は設定とともに保存され、日本語環境では初期言語も日本語になります。曲名、ファイル名、パスは翻訳されません。

## 進行状況と問題の確認

ログ欄の「処理の概要」に主要な進行状況を表示します。問題を調べる場合は「詳細ログ」に切り替えるか、「詳細ログを保存…」で全記録を保存してください。自動スクロールを止めても、処理は継続します。

- **起動できない：** Windows x64 用の .NET 10 Desktop Runtime がインストールされているか確認します。
- **音源の確認に失敗する：** 表示された曲と原因を確認し、ファイルが読み取れるか、対応する無損失音声かを確認します。
- **空き容量が足りない：** 作業フォルダーと出力先の両方に空き容量が必要です。「詳細設定」で作業フォルダーを変更できます。
- **作成・検証に失敗する：** 詳細ログと対応する作業フォルダーを残して原因を修正し、再試行します。ISO が生成されただけでは検証完了ではありません。
- **コンポーネントが壊れている：** すべてのウィンドウを閉じて再起動します。改善しない場合は ZIP を展開し直します。必要なら終了後に `%LOCALAPPDATA%/DVD-Audio-Maker/runtime` を削除すると、次回起動時に再生成します。

完全な処理ログと起動エラーは `%LOCALAPPDATA%/DVD-Audio-Maker/logs` に保存されます。完成品の検証はディスクの構造、容量、曲の順序、時間、メニュー、全曲の音声データを確認します。検証のためにエンコード済みファイルを変更することはありません。
